> [!NOTE]
> Unless otherwise noted, the repositories in this organization are not officially supported IBM Quantum software.

[Qiskit](https://www.ibm.com/quantum/qiskit) is **the world's most popular and performant software stack for quantum computing and algorithms research**. It is maintained by IBM Quantum and a vibrant community of quantum enthusiasts. The official Qiskit Projects reside at [github.com/Qiskit](https://github.com/Qiskit).

The Qiskit Community GitHub organization serves various purposes, including:

*   Hosting code for Qiskit-related events
*   Piloting half-backed ideas or experimental code awaiting maturity
*   Housing projects not officially maintained by IBM (unless otherwise noted)
